# Hangout Tourist

A travel booking web app built with React, Vite, Tailwind CSS, and shadcn/ui.

## Features

- Flight search & booking
- Hotel listings
- Holiday packages
- Visa assistance
- Car rental
- Admin panel

## Tech Stack

- React (JSX)
- Vite
- Tailwind CSS
- shadcn/ui
- React Router
- TanStack Query

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
